System Features

  • Low Power Consumption: Thanks to LoRaWAN wireless technology, the battery life of devices lasts for months or even years.
  • Real-time Data: Thanks to the Firebase system, as soon as a sensor transmits data, it is displayed on the dashboard in real-time without reloading the page.
  • Independent Frontend: This web site runs completely independently of the backend server (as a pure static site).
  • Secure Communication: Data incoming from sensors to the server is validated and accepted using a secure API Key.
